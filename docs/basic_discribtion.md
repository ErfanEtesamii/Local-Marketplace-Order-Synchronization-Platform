# راهنمای ساده‌ی تعویض پروکسی

## ۱. وقتی صفحه‌ی status.html قرمز شد چیکار کنم؟

1. یک پنجره‌ی File Explorer باز کنید و به این مسیر بروید:
   `C:\OrderSyncPlatform`
2. فایلی به اسم **proxy.txt** را با Notepad باز کنید.
3. هر چی داخلش هست را پاک کنید و لینک پروکسی جدید را به‌جایش بچسبانید.
4. با کلید‌های Ctrl+S ذخیره کنید و فایل را ببندید.
5. همین! لازم نیست چیز دیگری را دستی خاموش یا روشن کنید. فقط چند ثانیه صبر کنید تا صفحه‌ی status.html خودش سبز شود.

## ۲. اگه بعد از چند دقیقه هنوز قرمزه چیکار کنم؟

1. به مسیر `C:\OrderSyncPlatform` بروید و روی فایل **start.bat** دوبار کلیک کنید.
   (این فایل فقط برای وقتی است که برنامه اصلاً خاموش شده باشد؛ لازم نیست هر بار که پروکسی را عوض می‌کنید این کار را انجام دهید.)
2. اگر یک پنجره‌ی سیاه باز شد و پیامی نشان داد، فقط یک کلید را فشار دهید تا بسته شود.
3. دوباره چند ثانیه صبر کنید و صفحه‌ی status.html را نگاه کنید.
4. اگر باز هم قرمز ماند، با [نام/شماره مسئول فنی] تماس بگیرید.

## ۳. صفحه‌ی سبز و قرمز چه شکلی است؟

- **سبز** یعنی همه‌چیز خوب است و پیام‌ها به‌درستی ارسال می‌شوند. روی صفحه نوشته شده: «✅ پروکسی متصل است».
- **قرمز** یعنی پروکسی قطع شده و باید لینک جدید را طبق بخش ۱ همین راهنما جایگزین کنید. روی صفحه نوشته شده: «❌ پروکسی قطع است».

پیشنهاد می‌شود یک shortcut از فایل `status\status.html` روی دسکتاپ بسازید، یا آن را همیشه در یک تب مرورگر باز نگه دارید تا هر وقت خواستید سریع رنگش را ببینید.
